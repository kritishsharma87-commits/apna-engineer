Explain the transformer attention mechanism in simple terms, then show me a Python snippet for scaled dot-product attention.

✦

Sure! Think of attention like a spotlight — for each word you're processing, it asks: "which other words in the sentence should I pay the most attention to right now?"

✦

Scaled dot-product attention computes: softmax(QKᵀ / √d_k) · V

Where Q (queries), K (keys), and V (values) are learned projections. The √d_k scaling prevents the dot products from growing too large and saturating the softmax.

✦

Here's a clean implementation:

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None: scores = scores.masked_fill(mask == 0, -1e9)
    return torch.matmul(F.softmax(scores, dim=-1), V)
